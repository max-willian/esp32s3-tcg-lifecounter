# ESP32 PV Counter

A touchscreen life counter for card games, running on an
ESP32-S3 with a 1.28-inch round LCD.

## Supported Games

- Star Wars Unlimited
- Magic: The Gathering

## Hardware

- ESP32-S3
- GC9A01A 240x240 LCD
- CST816S touchscreen
- 8 MB PSRAM
- 16 MB Flash

## Features

- Life point counter
- Game mode selection
- Configurable maximum PV
- Refresh confirmation
- Persistent settings

## Development

Developed using Arduino IDE and C++.
