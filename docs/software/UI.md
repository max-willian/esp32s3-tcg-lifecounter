# User Interface

## Display

- Resolution: 240x240
- Shape: Round
- Background: Dark
- Text: White

## Main Counter Screen

- Settings gear icon.
- Current game name.
- Current PV.
- Configured maximum PV.
- Refresh icon.

Touch areas:
- Top center: Settings.
- Right side: Increase PV.
- Left side: Decrease PV.
- Bottom center: Refresh confirmation.

## Settings Screen

- Maximum PV configuration.
- Game selection.
- Back button.

## Maximum PV Screen

- Current maximum.
- Decrease button.
- Increase button.
- Save button.

Limits:
- Minimum: 20.
- Maximum: 40.

## Refresh Confirmation Screen

- CERTEZA?
- SIM button.
- NAO button.
- 3-second timeout.

## Interaction

Touch coordinates determine the selected UI area.
The circular screen shape must be considered when positioning
elements.
