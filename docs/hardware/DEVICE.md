# Hardware Device

## Board

Manufacturer: SpotPear

Model: ESP32-S3-Touch-LCD-1.28-BOX-THIN

## Microcontroller

- ESP32-S3
- Flash: 16 MB
- PSRAM: 8 MB

## Display

- Controller: GC9A01A
- Size: 1.28 inches
- Resolution: 240x240
- Shape: Round

## Touchscreen

- Controller: CST816S
- Communication: I2C
- Address: 0x15

## Development Environment

- Operating System: Windows
- IDE: Arduino IDE
- Language: C++
- Serial: 115200 baud
